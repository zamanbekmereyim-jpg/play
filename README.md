# ♟️ Q-PLAY | Female Strategic Alliance

> Elite intellectual hub for women. Strategic logic and digital impact.

Официальный сайт сообщества шахматисток **Q-PLAY**, основанного Мерейкой.

## 🚀 Стек технологий

- **Фреймворк**: Next.js 14+ (App Router)
- **Стили**: Tailwind CSS
- **Анимации**: Framer Motion
- **Иконки**: Lucide React
- **Язык**: TypeScript
- **Локализация**: EN / RU (двуязычный)

## 📦 Запуск локально

```bash
# Установка зависимостей
npm install

# Запуск сервера разработки
npm run dev
```

Откройте [http://localhost:3000](http://localhost:3000) в браузере.

## 🌐 Деплой

Сайт оптимизирован для деплоя на [Vercel](https://vercel.com).
